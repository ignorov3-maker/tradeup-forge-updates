# TradeUp Forge — обновления

Отсюда приложение TradeUp Forge проверяет и скачивает новые версии.

- `latest.json` — номер последней версии, имя файла и его SHA-256.
- `TradeUp-Forge-X.Y.Z.forge-update` — сам файл обновления.

Приложение скачивает файл, сверяет SHA-256 и что это именно TradeUp Forge, и ставит только после нажатия «Установить».
